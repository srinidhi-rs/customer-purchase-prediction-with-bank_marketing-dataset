# 📊 Bank Marketing - Decision Tree Classifier

This project is a complete Machine Learning pipeline that predicts client subscription to term deposits based on the **Bank Marketing Dataset**.

## 🔍 Project Overview

The dataset contains marketing campaign data from a Portuguese bank. The goal is to predict whether a client will subscribe to a term deposit (`yes`/`no`) using a Decision Tree Classifier.

## 📁 Features

- ✅ Supports multiple CSV file ingestion and validation.

- 🧹 Preprocesses data (null check, encoding, target mapping).
  
- 🌲 Trains a Decision Tree Classifier (entropy-based).
  
- 📈 Evaluates model using:
  
  - Accuracy
  - Confusion Matrix
  - Classification Report
    
- 📉 Visualizes:
  
  - Decision Tree Plot
  - Confusion Matrix Heatmap
- 🔎 Includes single-sample prediction.

## 🛠️ Technologies Used

- Python 3.x  
- Pandas  
- NumPy  
- scikit-learn  
- Matplotlib  
- Seaborn

## 📦 How to Run

1. Clone the repository.
2. Place your `.csv` files in the `data/` folder.
3. Run the Python script.
